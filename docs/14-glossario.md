# Glossario del percorso

[Percorso](../README.md)

| Termine | Significato nel dossier |
|---|---|
| Base di conoscenze / KB | Raccolta organizzata di catalogo, mappa e registro, con limiti e verifiche |
| Contesto corrente | Informazioni effettivamente disponibili al modello nel momento del lavoro; non necessariamente tutta la KB |
| Catalogo | Elenco delle fonti con identità, posizione e motivo della scelta |
| Mappa | Rappresentazione di concetti collegati da relazioni esplicite |
| Claim / affermazione | Frase di contenuto di cui possiamo discutere ambito e sostegno |
| Registro | Raccolta di affermazioni, fonti e posizioni, esiti e motivazioni |
| Ancoraggio | Riferimento al punto preciso in cui controllare una frase; nel dossier usiamo “fonte e posizione” |
| Inferenza | Conclusione ricavata ragionando da premesse dichiarate, non necessariamente espressa dalla fonte |
| Intento | Problema educativo e risultato desiderato |
| Specifica | Descrizione di destinatari, obiettivi, requisiti, vincoli e criteri di accettazione |
| Obiettivo | Ciò che si vuole ottenere; qui una capacità dello studente |
| Prestazione osservabile | Ciò che lo studente fa per mostrare quella capacità |
| Vincolo | Condizione obbligatoria da rispettare durante la progettazione o nel risultato |
| Requisito | Caratteristica richiesta al prodotto, scelta dal progettista |
| Criterio di accettazione | Condizione controllabile per decidere se il prodotto soddisfa la specifica |
| Evidenza | Riscontro concreto su cui si basa il controllo |
| Esito | Risultato motivato di quel controllo, riferito a un oggetto preciso |
| Piano | Ordine delle attività e allocazione di tempi e risorse |
| Compito | Attività concreta con cui si attua il piano |
| Prova di apprendimento | Attività che raccoglie risposte degli studenti per valutare gli obiettivi |
| Scheda di revisione | Documento che conserva valutazioni, evidenze e decisioni sulle parti esaminate |

Il prompt comunica una richiesta al modello e può contenere una specifica. La specifica documenta i requisiti e permette di controllare e riusare le scelte; non garantisce che il prodotto le rispetti senza revisione.
